# Ad Frame Prompt Lab

제품명·소구점·비주얼 스타일(8종)·컷 수(3~6)로 광고 영상용 Start Frame / End Frame /
Storyboard 프롬프트(한글·영문)를 만드는 도구입니다.

## 동작 방식

이 저장소는 API 키·서버·로그인 기능이 없는 공개 정적 사이트라 페이지가 직접 AI를
호출하지 않습니다. 대신 두 단계로 나눕니다.

1. **입력 → 지시문**: 입력값으로 Claude에 붙여넣을 지시문(컨셉 설계 + 컷별 프레임 규칙 +
   JSON 출력 형식)을 조립해 복사합니다.
2. **JSON 붙여넣기 → 컷별 정리**: Claude가 돌려준 JSON을 붙여넣으면 컷 아코디언으로
   정리하고, 블록별 복사와 전체 복사를 제공합니다.

입력과 붙여넣은 결과는 브라우저 안에서만 처리합니다(저장·전송·URL 직렬화 없음).

## 고치는 곳

스타일 목록, 컷 수 옵션, 컷 흐름, 지시문 문구는 모두 `prompt-config.js` 한 파일입니다.
