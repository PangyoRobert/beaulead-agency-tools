# YouTube Creator Affiliate Quote

카페24 · 유튜브 쇼핑 크리에이터 제휴의 **경향 확인용** 역산 계산 페이지입니다. 계약 전 고객사와 규모감을 맞추는 용도이며, 성과를 보장하거나 손익을 계산하는 도구가 아닙니다.

## 입력 5개

| 변수 | 기본값 | 근거 |
| --- | --- | --- |
| 목표 ROAS | 없음 | 고객사가 제시하는 값이라 기본값을 두지 않습니다 |
| 객단가 | 없음 | 범용성을 위해 직접 입력합니다 |
| 콘텐츠 지원비 | 150,000원 | 확정 범위 10만~20만원의 중앙값, 전원 동일 지급 |
| CPS 과금 수수료율 | 15% | 확정값. 한번 정하면 캠페인 내내 유지합니다 |
| 인플루언서 명수 | 없음 | 모집 결과가 변동하므로 3개 시나리오를 함께 봅니다 |

카페24 수수료 5%는 입력이 아니라 **자동 계산**입니다. 콘텐츠 지원비 총액(지원비 × 명수)에 붙는 확정 요율이라 화면에서 바꿀 수 없습니다.

## 계산식

```
1인당 지출         = 지원비 × (1 + 카페24 수수료율)
1인당 필요 매출     = 1인당 지출 ÷ (1 / 목표ROAS − CPS 수수료율)
1인당 필요 판매수량  = 1인당 필요 매출 ÷ 객단가

총 매출        = 1인당 필요 매출 × 명수
총 지원비       = 지원비 × 명수
카페24 수수료    = 총 지원비 × 카페24 수수료율
총 CPS 수수료   = 총 매출 × CPS 수수료율
총 비용        = 총 지원비 + 카페24 수수료 + 총 CPS 수수료
```

예산에서 명수를 거꾸로 풀 때는 `명수 = 예산 × (1 − CPS수수료율 × 목표ROAS) ÷ (지원비 × (1 + 카페24수수료율))` 입니다. 카페24 수수료가 지원비에 비례한 덕분에 명수가 한 항으로 묶여 나눗셈 한 번으로 풀립니다.

## 알아둘 성질 두 가지

**명수는 1인당 지표와 ROAS를 바꾸지 않습니다.** 지원비, 카페24 수수료, 매출이 모두 명수에 비례하므로 식에서 약분됩니다. 카페24 수수료를 명수와 무관한 고정비로 잡았다면 이 성질이 깨졌을 것입니다 — 지원비에 비례하는 값이라 깨지지 않습니다. 명수가 바뀌면 총 규모만 비례해서 변합니다. 시나리오 표의 ROAS 행이 항상 같은 값인 이유입니다.

**수수료율이 ROAS 상한을 결정합니다.** 총비용에 `매출 × 수수료율`이 항상 포함되므로 도달 가능한 ROAS는 `1 ÷ 수수료율` 미만입니다. CPS 15%면 상한은 6.67배이고, 지원비가 0원이어도 넘을 수 없습니다. 상한 이상을 입력하면 계산하지 않고 이유를 표시합니다.

## ROAS 범위

분모는 **크리에이터 지원비, 카페24 수수료, CPS 수수료**를 포함합니다. 고객사는 보통 총 투입비 기준으로 생각하므로, 화면과 복사 요약에 이 범위를 항상 함께 표기합니다.

설정값은 `pricing-config.js`, 계산 규칙은 `calculator.js`에서 관리하며 검증은 `scripts/test_youtube_creator_quote.js`가 담당합니다.
