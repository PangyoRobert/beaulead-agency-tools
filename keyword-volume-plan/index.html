02. 화면 영역별 명세

01 / 키워드 입력

단일 키워드 입력 → 조회 버튼 또는 Enter → 결과 확인. 앞뒤 공백만 제거하고 원문을 유지합니다. 빈 입력은 요청하지 않고 입력란 가까이에 안내합니다.

실서비스 버튼명: ‘검색량·입찰가 조회’. 요청 중 중복 조회를 막고, 결과가 오면 응답의 키워드를 표시합니다.

02 / 디바이스별 결과

PC·모바일을 먼저, 합계를 보조 카드로 보여줍니다. 단위는 ‘회’, 정수는 천 단위 쉼표로 표기합니다. 디바이스 구분은 모바일에서도 유지합니다.

PC와 모바일 수치는 검색 횟수이며, 중복을 제거한 사용자 수가 아닙니다.

03 / 출처와 조회 정보

네이버 검색광고 키워드도구, 응답 키워드, 조회 시각(KST)을 결과에 붙입니다. 검색량과 PC·모바일 입찰가의 출처 및 조회 시각은 각각 관리합니다. 제공 기준을 확인하기 전에는 ‘지난달’ 또는 특정 날짜 범위로 이름 붙이지 않습니다.

04 / 상태와 복구

조회 전에는 입력 안내, 로딩 중에는 진행 상태, 빈 결과에는 키워드 수정 안내, 실패 시에는 재시도 안내를 표시합니다. 이전 키워드의 수치를 새 결과처럼 남겨두지 않습니다. 검색량·PC 입찰가·모바일 입찰가를 독립적으로 처리하여, 한 요청이 실패해도 성공한 영역은 유지합니다. 실패한 영역만 재시도하며, 키워드를 바꾼 뒤 도착한 이전 응답은 무시합니다.

05 / PC 순위별 입찰가

검색량 아래에 1~8위 순서의 표를 제공합니다. ‘목표 순위 / 평균 예상 입찰가(원)’를 표시하고, 응답 순서가 바뀌어도 position 기준으로 정렬합니다. 누락된 순위는 ‘제공 없음’으로 표시합니다.

06 / 모바일 순위별 입찰가

PC 표 옆에 1~5위 표를 배치합니다. 좁은 화면에서는 PC 다음에 모바일 표가 이어집니다. 6~8위는 요청하지 않으며 0원이나 추정값으로 채우지 않습니다. 모바일 한도 안내는 항상 표시합니다.

03. 데이터 표시 기준

검색량은 기존 확인 기록, 입찰가는 2026.09.22 실제 API 응답을 기준으로 설계했습니다. PC 1~8위와 모바일 1~5위는 HTTP 200, 모바일 6·7·8위는 각각 HTTP 400 순위 제한을 확인했습니다.

화면 항목연결할 데이터표시·계산 규칙
응답 키워드relKeyword입력한 단어와 일치하는 응답인지 확인. 일치 항목이 없으면 관련 키워드를 대신 표시하지 않음.

모바일 월간 검색량monthlyMobileQcCntPC와 같은 규칙. 누락 값은 ‘제공 없음’으로 표시하며 0으로 바꾸지 않음.

이번 화면에 포함

단일 키워드 입력, PC·모바일 월간 검색량과 합계, PC 1~8위·모바일 1~5위 평균 예상 입찰가, 출처·조회 시각, 전체·부분 실패 상태.

후속 검토 범위

성별·연령·월별 추이, 연관키워드 비교, 입찰가 변경·저장 및 예상 노출·클릭·비용은 이번 설계에 포함하지 않습니다. 데이터랩 상대 지수를 절대 검색량으로 표시하지 않습니다.

실제 데이터 연결

승인된 백엔드에서 검색량 /keywordstool 1건과 POST /estimate/average-position-bid/keyword PC·MOBILE 각 1건을 조회합니다. 키워드 한 개당 총 3건이며, 각 응답을 독립 검증해 표시합니다.

구현 완료 판정

  • 검색량 및 입찰가의 keyword·device·position·bid가 원본 응답과 일치한다.
  • PC 1~8위 8행, 모바일 1~5위 5행을 순서대로 표시한다.
  • 모바일 6~8위 요청이 생성되지 않으며 누락 값을 임의 추정하지 않는다.
  • 검색량·PC·모바일 중 한 요청이 실패해도 다른 성공 결과는 유지된다.
  • 빠르게 키워드를 변경해도 이전 응답이 새 결과를 덮어쓰지 않는다.
  • 범위 값·누락·0을 서로 구분하고 부정확한 합계를 만들지 않는다.
  • 빈 입력, Enter 조회, 중복 요청 방지, 오류 후 재시도를 확인한다.
  • 새 조회 중 이전 결과가 현재 결과로 보이지 않는다.
  • 모바일 한 열 배치, 키보드 탐색, 상태 알림을 확인한다.
  • 인증정보가 HTML·JavaScript·로그에 노출되지 않는다.

다음 결정이 필요한 항목

  • 이용 대상: 사내 마케터 전용인지 외부 사용도 허용할지.
  • 실서비스 위치와 로그인·접근 제어 방식.
  • 검색량 집계 기간 및 입찰가 추정 기준·갱신 주기 확인.
  • 호출 제한, 캐시 유효기간, 운영 비용 정책.
