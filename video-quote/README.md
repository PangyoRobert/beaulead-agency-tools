# Video Quote

영상 길이·수량과 추가 옵션을 조합해 예상 견적을 확인하는 공개 계산 페이지입니다.

## 계산 범위

- 15초 / 30초 — 길이 무관 균일 단가
- 1분 — Standard / Deluxe 중 선택한 레벨의 단가
- 총 편수가 기준 편수 이상이면 기본 제작비에 볼륨 할인
- 추가 옵션 15종 (일부는 최소 기준가라 금액에 `~`가 붙습니다)
- 공급가에 VAT 별도 가산

단가·할인율·옵션 목록과 화면 문구는 `pricing-config.js`, 계산 규칙은 `calculator.js`에서 관리합니다. `index.html`에는 금액을 적지 않습니다. 설정에 없는 범위(기획 수정 횟수, 출장비, 매체비 등)는 계산하지 않습니다.

공개 페이지이므로 원가, 외주 단가, 마진은 이 디렉토리에 두지 않습니다.
