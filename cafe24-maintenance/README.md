# Cafe24 Maintenance

카페24 자사몰 6개월 단위 유지보수에 포함되는 업무, 별도로 산정하는 작업, 별도 비용을 한 장으로 안내하는 공개 페이지입니다. 제목은 "카페24 자사몰 유지보수 현황표"입니다.

## 확정 내용 (2026-10-06, 담당자 확인)

- 6개월 유지보수비 총액 100만원, 부가세 별도(공급가 기준), VAT 포함 110만원
- 3개월씩 2회 분할 납부 (회당 공급가 50만원은 총액을 균등 분할한 계산값)
- 6개월간 18회 이내
- 계약 기간은 6개월 단위만 안내합니다. 이전의 1개월(월) 단위는 삭제했고, 건별·연 단위는 내부 검토 후 제안하므로 넣지 않았습니다.
- 배너·상세페이지 제작, 신규 내용 추가, 디자인 변경은 유지보수비와 별개로 산정합니다.

## 정해지지 않아 쓰지 않은 것

- 18회를 넘는 요청의 처리 방식과 "1회"의 기준
- 6개월 계약 후 갱신 방식(자동 갱신 여부)
- 중도 해지·환불 기준
- 분할 납부 각 회차의 결제 시점
- 회당 투입 시간·내부 단가 (근거 산정에서 제외하기로 함)

## 업체명 모듈화

업체별 값(업체명·스킨·연동·작업 이력)은 `index.html` 안 `<script id="maintenance-config">`의 `client` 블록에만 있고, 아래의 화면 코드는 읽어서 그리기만 합니다. 본문에는 업체명을 쓰지 않습니다. 새 업체는 `client`만 바꿉니다.

기본값은 비어 있어 제목만 보입니다. 화면의 "업체명(선택)" 칸에 입력하면 제목 앞에만 붙고 URL·`localStorage`·외부 전송에는 남지 않습니다. 인쇄할 때는 입력칸이 숨겨집니다.

## 설정이 HTML 안에 있는 이유

설정을 별도 `.js` 파일로 두면 브라우저가 파일마다 따로 캐시합니다(GitHub Pages는 파일마다 `max-age=600`). 배포 직후 새로고침하면 HTML만 새로 받고 설정은 옛 캐시를 써서, 화면에 `undefined`·`NaN`이 보입니다(2026-10-06 실제 사고). 한 파일이면 어긋날 수 없습니다. `scripts/test_cafe24_maintenance.js`가 화면 코드를 실제로 실행해 `undefined`·`NaN`이 없는지 보고, 외부 `.js` 의존이 다시 생기면 실패합니다.

## 공개 저장소 규칙

공개 승인이 없는 실제 업체명·구매 내역·내부 단가는 이 디렉토리에 넣지 않습니다. `scripts/test_cafe24_maintenance.js`가 실제 업체명, 저장·전송 API, 원가·마진 표기를 검사합니다.

## 검증

```sh
python3 scripts/validate_site.py
node scripts/test_cafe24_maintenance.js
```
