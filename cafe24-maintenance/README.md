# Cafe24 Maintenance

카페24 자사몰 월 단위 유지보수에 포함되는 업무, 별도로 산정하는 작업, 별도 비용을 한 장으로 안내하는 공개 페이지입니다.

## 확정 내용 (2026-10-06, 담당자 확인)

- 월 유지보수비 50만원, 부가세 별도(공급가 기준)
- 월 포함 횟수 3회 이내
- 계약 방식은 월 단위만 안내합니다. 건별·연 단위는 내부 검토 후 제안하므로 넣지 않았습니다.
- 배너·상세페이지 제작, 신규 내용 추가, 디자인 변경은 월 유지보수비와 별개로 산정합니다.

## 정해지지 않아 쓰지 않은 것

- 월 3회를 넘는 요청의 처리 방식과 "1회"의 기준
- 회당 투입 시간·내부 단가 (근거 산정에서 제외하기로 함)

## 업체명 모듈화

업체별 값(업체명·스킨·연동·작업 이력)은 `maintenance-config.js`의 `client` 블록에만 있고 `index.html`은 읽어서 그리기만 합니다. 본문에는 업체명을 쓰지 않습니다. 새 업체는 `client`만 바꿉니다.

기본값은 가공 이름("○○스포츠")입니다. 화면의 "업체명" 칸에 입력하면 제목 자리만 바뀌고 URL·`localStorage`·외부 전송에는 남지 않습니다. 인쇄할 때는 입력칸이 숨겨집니다.

## 공개 저장소 규칙

공개 승인이 없는 실제 업체명·구매 내역·내부 단가는 이 디렉토리에 넣지 않습니다. `scripts/test_cafe24_maintenance.js`가 실제 업체명, 저장·전송 API, 원가·마진 표기를 검사합니다.

## 검증

```sh
python3 scripts/validate_site.py
node scripts/test_cafe24_maintenance.js
```
