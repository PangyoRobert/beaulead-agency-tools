# GFA Allowable CPM

네이버 GFA 보고서 표(이미지 유형·소재 유형별)를 붙여넣고 목표 ROAS를 넣으면, 유형마다 **CPM·CPC·CPA를 얼마까지 허용할 수 있는지**와
**어느 단계(클릭률·구매 전환율·객단가·CPM)가 병목인지** 보여 주는 내부용 계산기입니다. 정의서: `docs/gfa-allowable-cpm-calculator.md`.

CPM은 결과값이라 낮다고 좋은 게 아닙니다. 그래서 "적정 CPM"이 아니라 목표 ROAS를 지킬 수 있는 **허용 CPM 상한**과 비교합니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `gfa-config.js` | 판정 기준값(최소 구매 수 30·z 1.96·병목 기준 최소 행 3), 열 이름 별칭, 가상 예시 표. 바뀌는 값은 여기뿐입니다. |
| `calculator.js` | 표 읽기, 합계 행 추정, 파생 지표, 허용 상한, 판정, 병목 분해. Node와 브라우저에서 같이 씁니다. |
| `index.html` | 입력과 결과를 그립니다. 입력값은 `textContent`로만 그립니다. |

## 규칙

- **목표 ROAS는 기본값이 없습니다.** 광고주 마진에서 정해지는 값이라 화면에서 직접 넣습니다.
- 판정은 구매 수만 보는 오차폭 `1.96 ÷ √구매 수` 밖일 때만 "여유/초과"이고, 안이면 "경계", 구매 30건 미만이면 "표본 부족"입니다. 임의의 ±% 띠는 없습니다.
- 매출은 플랫폼 귀속값이고 부가세 기준이 광고비와 같아야 해서, 화면의 확인 체크를 해야 결과가 나옵니다.
- 합계 행은 다른 행의 합과 같으면 자동으로 체크하고(수동 변경 가능), 병목 비교 기준에서 뺍니다.
- 광고주 실제 수치는 이 공개 저장소에 두지 않습니다. 예시·테스트는 가상 값만 씁니다. 입력은 URL·`localStorage`·외부 전송 어디에도 남기지 않으며 `scripts/test_gfa_allowable_cpm.js`가 그런 API가 소스에 없는지 검사합니다.
- 공개 범위: 내부용(`public: false`, 2026-10-14 확정). 고객 시연이 필요해지면 `data/tools.json`에서 바꿉니다.

## 검증

```sh
node scripts/test_gfa_allowable_cpm.js
```
