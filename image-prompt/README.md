# Image Prompt Variant

기존 이미지 생성 프롬프트에 "바꿀 점"(계절·배경·인물·분위기 등)을 반영한 영문 프롬프트를
만드는 도구입니다.

## 동작 방식

이 저장소는 API 키·서버·로그인 기능이 없는 공개 정적 사이트라 페이지가 직접 AI를
호출하지 않습니다. `ad-frame-prompt`와 같은 두 단계로 나눕니다.

1. **입력 → 지시문**: 기존 프롬프트(선택)와 바꿀 점을 받아 Claude에 붙여넣을 지시문을
   조립해 복사합니다.
2. **답변 붙여넣기 → 정리**: Claude 답변의 `[ENGLISH PROMPT]` / `[NEGATIVE PROMPT]` /
   `[바뀐 부분]` 구간을 나눠 보여 주고 복사합니다.

기존 프롬프트는 사용할 때 화면에 붙여넣는 값이며 저장·전송·URL 직렬화를 하지 않습니다.
고객사 프롬프트를 저장소에 넣지 마세요(공개 저장소).

## 고치는 곳

- 선택지·생성기 규칙·지시문 문구: `image-prompt-config.js`
- 지시문 조립·결과 파싱: `prompt-builder.js` (테스트: `scripts/test_image_prompt.js`)

체형은 몸무게(kg)가 아닌 눈에 보이는 표현으로만 선택지를 둡니다. 숫자는 "체형 참고 수치"로
받아 Claude가 묘사로 바꾸게 합니다.
