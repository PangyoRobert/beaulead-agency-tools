# Shorts Editor

대본을 문장별 장면으로 나누고, 장면마다 **영상·이미지를 넣어 자르고**, 자막·효과음·화면 움직임을 붙여 **MP4로 내보내는** 브라우저 편집기입니다.
영상·이미지·소리 파일은 사용자의 브라우저 메모리에서만 처리하고 어디에도 저장하거나 보내지 않습니다(서버 없음, 새로고침하면 작업이 사라짐).

## 파일

| 파일 | 역할 |
| --- | --- |
| `shorts-config.js` | 화면 비율, 자막 기본값·글꼴, 움직임·효과음 목록, 길이 추정 기준값. 바뀌는 값은 여기뿐입니다. |
| `engine.js` | 문장 나누기, 자막 끊기, 장면 길이, 타임라인, 영상 구간(자르기), 화면 움직임·맞춤, 소리 일정. DOM이 없어 Node로 테스트합니다. |
| `sfx.js` | 파일 없이 만드는 합성 효과음 9종(클릭·뿅·딩·띠링·휙·타건·탭핑·물방울·모닥불). |
| `app.js` | 화면: 보관함, 장면 목록, 캔버스 그리기, 재생, MP4 내보내기, 영상 자르기. |
| `index.html` | 레이아웃과 스타일(토큰 색만 사용). |

## 동작 방식

- 장면 길이 우선순위: 목소리 파일 길이 > 직접 정한 길이 > 글 읽기 추정(글자 수 ÷ 5.2/초) > 영상 구간 길이 > 정지 3초. 거기에 "끝에 더 보여주기"를 더합니다.
- 화면을 고르지 않은 장면은 앞 장면 화면을 이어서 씁니다(영상이면 끊김 없이 이어 재생, 구간 끝에서는 마지막 프레임에서 멈춤).
- 영상 자르기는 원본을 건드리지 않고 남길 구간(시작·끝)만 기억해 미리보기와 내보내기에 반영합니다.
- 내보내기는 캔버스 + 오디오 믹스를 `MediaRecorder`로 **미리보기 속도로 녹화**합니다(영상 길이만큼 걸림). MP4(H.264/AAC)를 지원하는 Chrome·Edge는 MP4, 아니면 WebM이 나옵니다.

## 만들지 않은 것·한계

- **서버 저장·공유·계정·클라우드 렌더링**: 정적 사이트라 없습니다.
- **컴퓨터 목소리(TTS)를 파일로 받기**: 브라우저 TTS는 소리 파일을 주지 않습니다. 미리 듣기만 되고, MP4에 넣으려면 녹음한 목소리 파일을 쓰거나 내보내기의 "탭 소리 공유"(화면 공유 창에서 탭 오디오 공유)를 켭니다.
- **내 목소리 TTS(학습)**: GPU와 로컬 설치가 필요해 이 사이트에서는 불가능합니다. 만든 목소리 파일(mp3·wav)을 넣는 기능은 있습니다.
- **프로젝트 저장·불러오기(zip)와 자동 저장**: 저장소 규칙(입력값 비저장)과 영상 용량 때문에 넣지 않았습니다.
- 매우 큰 영상(1GB 이상)·일부 HEVC 영상은 브라우저에 따라 열리지 않거나 멈춥니다.
