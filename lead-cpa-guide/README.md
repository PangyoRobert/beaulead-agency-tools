# Lead CPA Guide

업종·제품별 리드(DB) 1건당 평균 단가를 2025년 1분기 원자료와, 여기에 10%를 반영한
2026년 참고가로 함께 보여주는 참고표입니다.

## 원자료와 출처

원자료는 업계에서 공유된 「2025년 1분기 업종별 DB CPA 마케팅 평균 단가표」로,
Microsoft Teams 채팅 파일로 전달받았습니다. **뷰리드 자체 집행 데이터가 아니라
외부에서 공유된 시장 벤치마크 자료**입니다. 원자료에 표기된 회사명은 이 저장소
어디에도 옮기지 않았고, 숫자만 참고 자료로 재구성했습니다.

## 10% 반영은 실측치가 아니다

`pricing-config.js`의 `base`가 원자료 값이고, 화면은 `inflationRate`(0.1)를 곱해
2026년 참고가를 계산합니다. **이 10%는 사용자가 지정한 일괄 조정값**이며 실측
인플레이션이 아닙니다. 그래서 화면은 원자료 단가를 감추지 않고 조정가와 항상
나란히 보여줍니다. 인상률을 바꾸려면 이 값 하나만 고치면 됩니다.

## 부가세

원자료에 VAT 표기가 없어 이 파일과 화면 모두 부가세 언급 없이 단가를 그대로
둡니다. 포함인지 별도인지는 확인 전이라고 화면에 명시했습니다.

## 공개 상태 — 아직 배포하지 않음

`data/tools.json`에 `public: false`로 등록했습니다. 원자료가 외부 자료라 그대로
공개해도 되는지(저작권·출처 표기) 확인이 끝나지 않아서입니다. 공개 여부를
결정한 뒤 `public`을 바꿉니다.
