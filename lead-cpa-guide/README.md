# Lead CPA Guide

업종·제품별 리드(DB) 1건당 평균 단가를 2025년 1분기 원자료와, 여기에 10%를 반영한
2026년 참고가로 함께 보여주는 참고표입니다.

## 원자료와 출처

뷰리드가 정리한 2025년 1분기 업종별 DB CPA 평균 단가 참고 자료입니다. **뷰리드가
직접 집행해 얻은 측정치라고 단정하지 않으며**, 참고용으로 정리한 자료라는 표현을
화면과 이 문서에 그대로 씁니다.

## 10% 반영은 실측치가 아니다

`pricing-config.js`의 `base`가 원자료 값이고, 화면은 `inflationRate`(0.1)를 곱해
2026년 참고가를 계산합니다. **이 10%는 사용자가 지정한 일괄 조정값**이며 실측
인플레이션이 아닙니다. 그래서 화면은 원자료 단가를 감추지 않고 조정가와 항상
나란히 보여줍니다. 인상률을 바꾸려면 이 값 하나만 고치면 됩니다.

## 부가세

원자료에 VAT 표기가 없어 이 파일과 화면 모두 부가세 언급 없이 단가를 그대로
둡니다. 포함인지 별도인지는 확인 전이라고 화면에 명시했습니다.

## 공개 상태

`data/tools.json`에 `public: true`로 등록해 배포합니다.
