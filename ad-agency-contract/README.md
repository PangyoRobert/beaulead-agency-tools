# Ad Agency Contract

고객사 정보와 계약 조건을 입력해 디지털 광고 대행 계약서를 만들고 A4로 인쇄(PDF 저장)하는 페이지입니다.
원본은 2026.08.20 디지털 광고 대행 계약서(PDF 5쪽)입니다.

## 파일

- `contract-config.js` — 조항 원문, 뷰리드(을) 정보와 입금계좌, 관할법원, 기본 문구. 조항을 고칠 때는 이 파일만 고칩니다.
- `contract.js` — 입력값과 설정으로 문서 모델을 만드는 로직(날짜·기간 문구, 번호 매기기, 견적서1 계산, 검증).
- `index.html` — 입력 폼과 A4 미리보기. 입력값은 `textContent`로만 그립니다.

## 입력하는 값

- 갑: 상호, 브랜드명(전문의 “본 사업”), 사업자번호, 직함·대표자명
- 계약 체결일, 시작일, 종료일 — 제4조 1항은 정확히 n개월이면 “n개월간”, 아니면 “종료일까지”로 씁니다.
- 계약명, 대금지급조건, 총계약금액 문구, 붙임문서
- 견적서1(선택): 매체별 월 광고비 × 대행수수료율. 수수료는 원 단위 반올림, VAT 별도. 켜면 총계약금액과 붙임문서가 표를 따릅니다.
- 특약사항(선택): 마지막 조 다음 조로 붙습니다.

## 공개 저장소 규칙

- 고객사 정보는 커밋하지 않습니다. 샘플과 테스트는 “주식회사 ○○” 같은 가공 값만 씁니다.
- 입력값은 URL, `localStorage`, 외부 전송 어디에도 남기지 않습니다. `scripts/test_ad_agency_contract.js`가 그런 API가 소스에 없는지 검사합니다.
- 뷰리드 입금계좌는 2026-09-30 공개 승인을 받아 설정 파일에 둡니다.

## 원본과 다른 점

- 항은 ①②, 호는 1. 2. 로 자동 번호를 매깁니다. 원본은 번호가 깨져 제3조 1항·제8조 1항의 호가 2부터 시작했습니다. 내용은 그대로 두고 번호만 1부터 다시 매겼습니다.
- 원본 전문에 남아 있던 “브랜드명” 자리표시와 표지·서명란의 상호 불일치는 입력값 하나로 채워 없앴습니다.
- 문장 끝 마침표 누락(제4조 1·3항, 제7조)과 제8조 4항의 따옴표 짝을 바로잡았습니다.

## 보완 예정 (미결)

- 제3조 1항·제8조 1항에서 누락된 원래 1호의 문구
- 제7조의 청구일·지급기한 — 원본은 “아래 내용에 따라”라고 하지만 아래에는 입금계좌만 있습니다.
