# F&B 로컬 시딩 가이드

F&B 업체 상담에서 체험단, 로컬 인플루언서, 지역 파워페이지와 UGC 제작자의
차이를 설명하고 비용·권리·측정 구조를 확인하는 공개 안내 페이지입니다.

## 범위

- 고객사·매장별 가격이나 성과 수치는 포함하지 않습니다.
- 크리에이터 후보나 견적은 저장하지 않습니다.
- 체크리스트는 현재 브라우저에서만 작동하며 저장·외부 전송하지 않습니다.
- 광고·협찬 표시는 공정위와 Instagram의 공식 기준을 링크합니다.

## 검증

node scripts/test_fnb_seeding_guide.js
