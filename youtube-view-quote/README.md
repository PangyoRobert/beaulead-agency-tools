# YouTube View Quote

유튜브 조회수 보장형 광고 상품 3종의 가격과 진행 조건을 안내하고, 집행 금액에 따른 보장 조회수를 계산해 주는 공개 페이지입니다.

## 상품 범위

- 1만 조회 보장 · 990,000원
- 2만 조회 보장 · 1,990,000원
- 3만 조회 보장 · 2,890,000원

## 금액 → 보장 조회수 계산기 (2026-11-23)

처음에는 패키지 가격이 조회수에 정비례하지 않아, 임의 입력 금액과 패키지 금액이 서로 어긋난다는 이유로 계산기 없이 가격표로만 만들었습니다. 그 문제는 **패키지 3종을 기준점으로 삼고 그 사이를 구간별 직선 보간**하는 방식으로 풀었습니다. 패키지 금액을 넣으면 패키지의 보장 조회수가 정확히 나오므로 두 숫자가 어긋나지 않습니다(테스트가 고정).

- 계산 로직은 `calculator.js`, 기준점은 `pricing-config.js`의 `packages`입니다. 새 단가를 따로 두지 않습니다.
- 허용 범위는 최저 패키지~최고 패키지 금액(990,000~2,890,000원 공급가)입니다. 범위 밖은 연장하지 않고 안내 문구만 보여 줍니다.
- 조회수는 내림합니다. 약정보다 많이 말하지 않기 위해서입니다.
- 입력 단위(`inputStep` 10,000원)와 기본 입력값은 **제안값이며 담당자 확정 대기**입니다. 하한·상한·보장 표기·VAT 기준의 확정 여부는 `docs/youtube-view-quote-history.md` 3절에 있습니다.

## 조회당 단가를 화면에 쓰지 않는다

구매 검토자가 구글 광고에 익숙하지 않은 상품이라 조회당 단가·조회율 같은 운영 지표는 판매 대화에서 다루지 않습니다. 화면에도 표시하지 않고, `pricing-config.js`에도 넣지 않습니다.

## 계정 권한 제한은 성과 확인 수단과 한 묶음이다

보장형은 뷰리드 통합 계정에서 집행하므로 고객사에 광고 계정 권한을 드리지 않습니다. 이 조건만 따로 적으면 근거 없는 제약으로 읽혀서, 성과를 직접 확인하는 두 가지 방법(유튜브 스튜디오 교차 확인, 원본 수치 기반 정기 리포트)과 같은 섹션에 묶어 두었습니다. 테스트가 세 항목이 함께 있는지, 그리고 같은 말이 안내 사항에서 중복되지 않는지 확인합니다.

GDN 상품의 유입 검증(GA4·웹솔루션 분석 도구) 안내는 이 페이지 범위 밖이라 넣지 않았습니다. 테스트가 해당 표현이 새어 들어오는지도 봅니다.

## 값의 위치

가격·보장 조회수·예상 노출·진행 단계·안내 문구는 전부 `pricing-config.js`에 있습니다. `index.html`은 그 값을 읽어 그리기만 하며 금액을 따로 적어 두지 않습니다. 추후 뷰리드 내부 워크스페이스용 비공개 버전이 만들어지면 같은 파일을 원본으로 읽어 두 곳의 가격이 어긋나지 않게 합니다.

공개 저장소이므로 원가, 매체비 비중, 마진은 이 디렉토리에 두지 않습니다.
