# YouTube View Quote

유튜브 조회수 보장형 광고 상품 3종의 가격과 진행 조건을 안내하는 공개 페이지입니다.

## 상품 범위

- 1만 조회 보장 · 990,000원
- 2만 조회 보장 · 1,990,000원
- 3만 조회 보장 · 2,890,000원

## 계산기가 아니라 가격표다

보장 조회수가 정해진 패키지 상품이라 고객이 입력할 값이 없습니다. 임의 조회수를 넣어 금액을 뽑는 기능은 넣지 않았습니다. 패키지 가격이 조회수에 정비례하지 않아서, 임의 입력 금액과 패키지 금액이 서로 어긋나는 화면이 되기 때문입니다.

## 조회당 단가를 화면에 쓰지 않는다

구매 검토자가 구글 광고에 익숙하지 않은 상품이라 조회당 단가·조회율 같은 운영 지표는 판매 대화에서 다루지 않습니다. 화면에도 표시하지 않고, `pricing-config.js`에도 넣지 않습니다.

## 계정 권한 제한은 성과 확인 수단과 한 묶음이다

보장형은 뷰리드 통합 계정에서 집행하므로 고객사에 광고 계정 권한을 드리지 않습니다. 이 조건만 따로 적으면 근거 없는 제약으로 읽혀서, 성과를 직접 확인하는 두 가지 방법(유튜브 스튜디오 교차 확인, 원본 수치 기반 정기 리포트)과 같은 섹션에 묶어 두었습니다. 테스트가 세 항목이 함께 있는지, 그리고 같은 말이 안내 사항에서 중복되지 않는지 확인합니다.

GDN 상품의 유입 검증(GA4·웹솔루션 분석 도구) 안내는 이 페이지 범위 밖이라 넣지 않았습니다. 테스트가 해당 표현이 새어 들어오는지도 봅니다.

## 값의 위치

가격·보장 조회수·예상 노출·진행 단계·안내 문구는 전부 `pricing-config.js`에 있습니다. `index.html`은 그 값을 읽어 그리기만 하며 금액을 따로 적어 두지 않습니다. 추후 뷰리드 내부 워크스페이스용 비공개 버전이 만들어지면 같은 파일을 원본으로 읽어 두 곳의 가격이 어긋나지 않게 합니다.

공개 저장소이므로 원가, 매체비 비중, 마진은 이 디렉토리에 두지 않습니다.
