# 메타 광고 CPM 아티클

"CPM이 높은 소재는 끄자"는 규칙을 CPA 상한 기준으로 바로잡는 기고용 아티클 페이지입니다.

## 수치 원칙

- 본문의 모든 숫자(CPM, CTR, 전환율, CPA, 상한 20,000원)는 설명용 **가상 수치**입니다. 실제 고객사·계정 데이터가 아닙니다.
- Grüns 창업자의 LTV:CAC 3배 사례는 영상을 통한 2차 인용이며 thisisgoingtobebig.com 원문 대조 전입니다.
- 메타 경매 구조 설명은 일반적으로 알려진 내용이며 Meta 공식 도움말 원문 확인이 남아 있습니다.

## 범위

- 고객 정보·비공개 성과 데이터는 포함하지 않습니다.
- 허용 CPA 상한·최소 표본의 구체 수치는 광고주별 결정 사항이라 싣지 않았습니다.
- 초안 원본 메모는 `docs/articles/meta-cpm-draft.md` (브랜치 `docs/meta-cpm-article-draft`).
