# Development Quote Prototype

내부 담당자가 홈페이지·랜딩 수정 및 상세페이지 작업의 예상 견적을 검토하는 익명 샘플 계산기입니다. 확정 견적, 계약 또는 결제 기능은 제공하지 않습니다.

## 적용 범위

- 홈페이지·랜딩 수정: 간단, 소규모, 중간규모, 대규모
- 상세페이지: 기존 부분 수정, 기존 전면 수정, 신규 제작
- 중간규모 이상 긴급 처리
- 영업·PM 수동 조정 요청 및 관리자 승인 시뮬레이션
- 예약, 결제, 회원, 외부 시스템 연동과 신규 홈페이지 제작은 별도 협의

가격과 판정 기준은 `pricing-config.js`, 계산 규칙은 `calculator.js`에서 관리합니다. 고객사별 실제 정보나 내부 원가·마진은 공개 저장소에 넣지 않습니다.
