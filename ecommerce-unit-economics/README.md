# Ecommerce Unit Economics

자사몰 1종을 기준으로 판매가·원가·물류비·PG 수수료를 넣으면 번들 구성(단품·1+1·2+1·3+1·4+1)별
광고 전 공헌이익(CM1), 손익분기 ROAS, 한계 CPA를 바로 계산하는 대면 시연용 시뮬레이터입니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `economics-config.js` | 가상 예시 기본값, 판정 기준값, 번들 구성, VAT율. 값이 바뀌는 곳은 여기뿐입니다. |
| `calculator.js` | 계산 공식과 입력 검증. Node와 브라우저에서 같이 씁니다. |
| `index.html` | 입력과 결과를 그립니다. 숫자를 따로 적어 두지 않습니다. |

## 기본값은 전부 가상 예시다

`defaults`는 실제 상품이나 고객사의 값이 아닙니다. 대면 미팅에서 바로 보여주려고 미리 채운
예시이며 화면에도 "가상 예시"라고 표시합니다. 공개 저장소이므로 실제 원가·마진은 넣지 않습니다.

## 어떤 방식을 채택했나

**입력이 같으면 결과가 항상 같은 회계 항등식만 씁니다.** 실제 손익과 어긋날 여지가 입력값의
정확도뿐이도록 했습니다.

- 채택: CM1, CM1율, 손익분기 ROAS, 한계 CPA, 개당 배송비, 제1·제3법칙 판정
- 뺀 것: 재구매·LTV 기반 CAC, 번들마다 같은 CPA를 가정하는 최종 마진, 소진 주기 기반 대량번들
  제한, 판정식을 확인하지 못한 제2법칙과 "추천/반려" 조합 판정
- **반품·취소는 반영하지 않는다(0% 가정).** 화면 결과 옆에 항상 이 전제를 적습니다.

## 금액 기준(VAT)

- 판매가는 결제금액이라 VAT를 포함합니다. 원가·물류비·광고 CPA는 공급가(VAT 제외)로 넣습니다.
- PG 수수료는 결제금액(VAT 포함)에 곱합니다.
- CM1은 공급가 매출에서 계산합니다. 그래서 VAT를 매출로 세는 계산보다 CM1이 낮습니다.
- 손익분기 ROAS = 결제금액 ÷ CM1. 광고 매체가 보고하는 구매 전환 가치와 같은 기준이고
  광고비(CPA)는 VAT 제외 금액입니다.

## 판정 기준값은 뷰리드 기획 기준이다

결제금액 4만 원 / CM1 2.5만 원(둘 중 하나 이상), CM1율 60%는 사용자의 시트 「이커머스 사전 계산
시스템」 5대 불문율에서 가져온 값입니다. 시장 표준이나 실측치가 아니라서 화면에서 바꿀 수 있게
열어 두었습니다. 값을 영구히 바꾸려면 `economics-config.js`의 `thresholds`만 고칩니다.

## 입력은 밖으로 나가지 않는다

계산은 브라우저 안에서만 합니다. `localStorage`, URL 파라미터, 네트워크 전송을 쓰지 않고
`scripts/test_ecommerce_unit_economics.js`가 그 경로가 없는지 검사합니다.

## 공개 상태

2026-10-06 `data/tools.json`에 `public: false`로 등록해 시작했고, 같은 날 공개(`public: true`)로
전환했습니다. 다시 내리려면 `public`을 `false`로 되돌리고 `python3 scripts/sync_registry.py --write`를
실행합니다.
