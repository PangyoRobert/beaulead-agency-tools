# Lead CPS Calculator

리드(DB) 수집 대행의 보수 구조를 비교하는 계산기입니다. 대출상담·인터넷 설치 같은
CPA형 업종에서 고정 수수료(광고비의 일정 %)를 받으면 생기는 문제 — 리드 품질 AS 요구,
공수 증가 — 를 보수 구조로 푸는 안을 숫자로 확인합니다.

## 원칙

품질 책임을 지려면 성과 보수를 받는다. 광고주가 품질 AS를 요구하는 순간 결과 책임을
묻는 것이므로 보수도 결과에 연동한다. AS를 요구하지 않으면 책임 범위를 줄이고 수수료를
낮춘다.

| 구조 | 대행사 책임 | 보수 |
| --- | --- | --- |
| 기존 고정 수수료 (비교 기준) | 광고 운영 (품질 AS 요구가 붙기 쉬움) | 광고비 × 기준 수수료율 |
| 1단계 라이트 CPA | 계약에 고정한 유효 DB 정의 충족까지 | 광고비 × 낮춘 수수료율 |
| 2단계 하이브리드 | 확정 건(승인·개통)까지 | 광고비 × 기본료율 + 확정 1건당 CPS |
| 3단계 순수 CPS | 소재·랜딩·DB 품질 전체 | 확정 1건당 CPS (월 최소 보장 선택) |

## 계산식

가정: 광고비는 광고주가 부담하고, 대행사 비용은 월 운영비뿐이다.

- 유효 DB = 광고비 ÷ CPA, 확정 건수 = 유효 DB × 백엔드 전환율
- 순수 CPS = 기준 수수료 ÷ 기준 전환율의 확정 건수 → 기준 전환율에서 광고주 비용이 기존과 같다
- 하이브리드 CPS = (기준 수수료 − 기본료) ÷ 기준 전환율의 확정 건수
- 내부 보기: 이익 = 수취액 − 월 운영비, 마진 = 이익 ÷ 수취액
- 최소 보장(MG): 손익분기 = 운영비, 목표 마진 = 운영비 ÷ (1 − 목표 마진)
- 1단계 손익분기 수수료율 = 운영비 ÷ 광고비

## 입력과 기본값

기본값이 있는 것은 사용자가 정한 값뿐이다: 민감도 전환율 5·8·12%, 기준 수수료율 15%,
목표 영업이익률 25%. 광고비·CPA·기준 전환율·1단계 수수료율·기본료율·월 운영비는 기본값이
없고 화면에서 직접 넣는다. 계정마다 달라지는 값이라 설정 파일에 두지 않았다.

업종 참고 CPA는 `../lead-cpa-guide/pricing-config.js`의 값(2026년 반영가)을 그대로 읽는다.
직접 집행한 실측이 아니므로 계약에는 해당 계정의 실측 CPA를 넣는다.

## 파일

- `cps-config.js` — 기본값, 구조 설명, 안전장치 문구. 문구를 고칠 때는 이 파일만 고친다.
- `calculator.js` — 순수 계산 함수. 입력이 같으면 결과가 같다.
- `index.html` — 입력 폼과 결과 표. 입력값은 `textContent`로만 그린다.

## 공개 저장소 규칙

- "내부 수익 보기"는 기본으로 꺼져 있다. 꺼진 상태에서는 운영비·이익·마진을 계산조차 하지 않는다. 광고주와 화면을 공유하기 전에 꺼 둔다.
- 입력값은 URL, `localStorage`, 외부 전송 어디에도 남기지 않는다. `scripts/test_lead_cps_calculator.js`가 그런 API가 소스에 없는지 검사한다.
- 실제 광고주 수치, 운영비, 마진은 이 저장소에 두지 않는다. 예시는 가상 값이다.

## 3단계(CPS) 필수 안전장치

확정 정의 고정 / 감사권(CRM 상태값 또는 월 정산 대조) / 환수(클로백) 범위 / 광고비 선지출
주체 / 정산 주기와 현금흐름.

## 미결

- 대출 성사 연동 보수의 법적 문제는 나중에 다룬다(2026-11-11 사용자 결정). 확인 전에는 대출 건에 3단계를 적용하지 않는 편이 안전하다.
- 대행사가 광고비를 선지출하는 구조는 아직 계산하지 않는다.
- 1단계 수수료율·하이브리드 기본료율의 제안값은 계정당 실제 운영 시간·시간 단가가 모이면 역산한다.
