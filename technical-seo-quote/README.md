# Technical SEO Quote

웹사이트 규모(소형 1-10 · 중형 10-50 · 대형 50+ 페이지)별 Technical SEO 작업 항목, 투입 시간, 투입 인원별 예상 비용을 안내하는 공개 견적 페이지입니다.

## 원본

구글 시트 「250204_Technical SEO 작업 견적서_초안_」(작성일 2026-01-15, 초안)의 4개 탭(핵심 요약·소형·중형·대형)을 옮겼다. 금액·시간·문구는 시트 값 그대로이고 임의로 만든 수치는 없다.

## 값의 위치

등급·항목·시간·비용·인원별 가격·기준 문구는 전부 `pricing-config.js`에 있다. `index.html`은 읽어서 그리기만 한다.

## 시트와 다르게 처리한 것

- **시간당 단가와 1MM(168시간) 산정 가정은 싣지 않는다.** 공개 저장소이므로 원가 역산 근거를 두지 않는다(2026-10-06 결정). 항목별 시간·비용·합계는 싣는다.
- **대형 사이트 1명·2명 가격은 시트가 비어 있어 `null`이다.** 화면에는 "별도 협의"로 나온다. 값을 추정해 채우지 않는다.
- 인원 배율이 등급마다 다르다(소·중형 2명 ×1.3, 중형 3명 ×1.5, 대형 3명 ×1.4). 시트 값을 그대로 쓰고 코드에서 배율로 계산하지 않는다.

## 검증

```sh
python3 scripts/validate_site.py
node scripts/test_technical_seo_quote.js
```

테스트는 항목 수와 시간·비용 합계가 시트 합계(120h/₩3,000,000 · 395h/₩9,875,000 · 860h/₩30,100,000)와 일치하는지, 설정에 단가·원가·마진이 새지 않았는지 확인한다.
